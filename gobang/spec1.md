# 五子棋游戏 · 开发计划与需求规格

> 版本 v2 · 编写日期 2026-08-20
> 全界面标注「制作：林森lsjs」

---

## 1. 项目概述与技术决策

| 项 | 决定 |
|---|---|
| 语言/框架 | Java 17 + JavaFX 21.0.2（Maven，现有 pom.xml） |
| 主类 | `org.example.gobang.Main`，`mvn javafx:run` 运行 |
| 测试 | JUnit 5（junit-jupiter 5.10.x + surefire 插件，**需在 pom.xml 新增**，当前无测试依赖） |
| 窗口 | 固定 800×900，不可缩放，全中文，每页标注「制作：林森lsjs」 |
| 架构 | 纯代码构建 UI（不用 FXML，减少文件与坑）；分层：model / logic / audio / fx |
| 线程 | UI 全在 FX 线程；AI 计算在 `Task` 后台线程；共享数据只有落子时的「生成号」竞态锁 |

## 2. 需求确认总表（来自问答确认）

- 模式：人机（简单/中等/困难AI）+ 双人同屏
- 棋盘 15×15，五连即胜（长连也胜），满盘平局；再来一局=交换黑白；重新开局=重新猜先
- 先手：猜先仪式（随机一方持子暗选 1 或 2 颗 → 另一方猜单/双 → 猜中执黑），完整动画+逐步音效
- 界面：程序绘制森林背景（天空渐变/远山/树影/草地）+ 8~10 片落叶装饰动画
- 交互：悬停半透明预览、点击吸附最近交叉点、非法落子抖动+提示音
- 音效（核心卖点，必须做到「爽」）：拟真敲击（黑低白脆+随机变调）、全套事件音效多变体随机播放、落子棋盘抖动、终局强震+屏幕晃动；BGM=中国风+森林自然音混合
- 设置：音乐/音效独立开关 + 独立音量滑条，持久化到 config.properties
- 功能：悔棋（每次1步：PvE 撤玩家+AI 共2子、PvP 撤最近2子，思考中/终局禁用）、终局五连高亮+花瓣特效+弹窗、AI 思考动画+落子预览
- 素材：从 Pixabay（免费无版权）下载，全部放入 resources
- 不做：积分统计、计时器、存档读档、认输

## 3. 详细技术设计

### 3.1 窗口布局精确规格（800×900 坐标系）

```
┌────────────── 800px ──────────────┐
│ 0~90   顶栏：标题「五子棋」+ 回合指示(轮到黑/白，棋子图标) + 「制作：林森lsjs」 │
│ 90~100 棋盘上边缘留白                                        │
│        棋盘区：原点(50,100)，单元格 50px，共 700×700         │
│        棋盘线：x = 50+i*50, y = 100+i*50 (i=0..14)           │
│        星位：(7,7)(3,3)(11,3)(3,11)(11,11) 画小实心圆         │
│        棋子半径 21px，边缘留 4px 防贴线                       │
│        鼠标坐标→索引：round((x-50)/50)，越界则 clamp 到[0,14] │
│ 800~900 底栏：左[悔棋][重新开局] 中:模式/难度文字 右:当前手数 │
└────────────────────────────────────┘
```

- 棋子绘制：黑子=近黑径向渐变(高光左上)+白描边；白子=乳白渐变+灰描边+淡阴影
- 棋子固定画在独立 `Canvas`，每步**全量重绘**（从历史快照重画，杜绝增量状态漂移）

### 3.2 状态机（唯一状态入口，防竞态核心）

```
GUESS ──猜先完成──> PLAYING
PLAYING ──人落子未分胜负(轮到AI)──> THINKING
PLAYING ──落子分胜负/满盘──> FINISHED
THINKING ──AI落子──> PLAYING | FINISHED
FINISHED ──再来一局──> PLAYING(交换黑白)   ──返回菜单──> 菜单页
任意态 ──重新开局(需确认)──> GUESS
```

- 所有交互（点击/悔棋/重开/弹窗按钮）第一行代码都是状态校验，非法则直接 return

### 3.3 数据模型（字段级设计）

```java
// Board.java
int[][] cells = new int[15][15];  // 0空 1黑 2白
boolean place(int r, int c, int color)      // 非法返回false
void remove(int r, int c)
boolean isFull()                            // 225格无空
List<Move> history                          // 完整落子记录，悔棋=removeLast×n

// Move.java: int row, col, color, seq
// GameState.java: 枚举 GUESS/PLAYING/THINKING/FINISHED
// GameContext: Board board, GameState state, int currentColor, 悔棋次数等
```

### 3.4 胜负判定算法（WinChecker.java）

- 对最后落子点做 4 方向检测：(0,1)(1,0)(1,1)(1,-1)
- 每方向从该点向两端延伸数同色连续数 `count`；`count>=5` 即胜（长连也算胜）
- 返回该方向的 5 个坐标列表（供高亮动画）
- 满盘且无胜 → 平局
- 唯一调用入口 `checkWin(board, lastMove)`，供 UI 与测试共用

### 3.5 猜先流程详细时序（GuessDialog）

```
1. 随机分配角色(50/50)：
   PvE: [人持子/AI猜] 或 [AI持子/人猜]
   PvP: [玩家1持/玩家2猜] 或 [玩家2持/玩家1猜]
2. 播报「随机决定：XX 持子」→ 音效+头像高亮动画
3. 持子方操作：
   人：面板显示两颗大按钮「握1颗」「握2颗」，点按→锁定音+选中高亮（隐藏结果）
   AI：显示「AI 握子中…」转圈 1~1.5s，AI 随机 1/2，不揭晓
4. 猜子方操作：
   人：「单数」「双数」两按钮；AI 同样 1~1.5s 动画后随机猜
5. 揭晓：鼓点音效+数字翻转动画显示「2 颗」，持子方结果揭晓
6. 判定音效：猜中=欢庆音效+金色特效；猜错=低沉音效
   结论文字：「猜对！XX 执黑先行」/「猜错！XX 执黑先行」
7. 弹窗关闭 → 黑方先行；若黑方是AI → 直接进入 THINKING 思考动画
```

### 3.6 AI 算法详细设计（logic/ai/）

**候选点生成 AICandidate**：遍历所有已落子，取其切比雪夫距离≤2 的空格，去重；若候选>30 个按「离中心近优先」截断。保证性能且不漏关键点。

**评分表 ScoreEvaluator**（对每个空格模拟下子后按方向评估）：

| 棋型 | 分值 |
|---|---|
| 活四（两端皆空） | 100000 |
| 冲四（一端堵） | 10000 |
| 活三 | 8000 |
| 眠三 | 1000 |
| 活二 | 500 |
| 眠二 | 100 |
| 其他 | 0 |

每格得分 = max(己方四方向得分)；攻防合成：`总 = 己方分 + 对方分×0.9`（防比攻略轻）

**三档差异**：
- `EasyAI`：检测对手是否成「四且一端空」→ 必堵；否则 60% 随机合法点、40% 取己方单点最高分
- `MediumAI`：对全部候选点算攻防总分，取最高（同分随机打破平局）
- `HardAI`：α-β 剪枝极小极大，深度=2 层；叶子节点估值=己方最高型分−对方最高型分；走法按启发式分降序排序（剪枝效率关键）；`long` 超时标记 2 秒，到时截断返回当前最优；每次评估前校验候选点非空，杜绝越界

**思考时序（GameView 内）**：状态→THINKING → 显示「AI 思考中…」转圈 → 后台 Task 计算 → 完成回调（**校验生成号**）→ 目标点呼吸光圈预览 0.5s → 落子+敲击音+轻震 → 胜负判定

### 3.7 音效系统设计（audio/）

**素材清单（resources/，sfx 用 wav、音乐用 mp3）**：

| 文件 | 用途 | 数量 |
|---|---|---|
| stone_black_1~4.wav | 黑子落子（低沉，4变体） | 4 |
| stone_white_1~4.wav | 白子落子（清脆，4变体） | 4 |
| win.wav / lose.wav / draw.wav | 终局 | 3 |
| click.wav / hover.wav | 按钮/悬停 | 2 |
| undo.wav | 悔棋 | 1 |
| guess_hold.wav / guess_pick.wav / guess_reveal.wav / guess_result_win.wav / guess_result_lose.wav | 猜先 5 环节 | 5 |
| leaf_rustle.wav | 落叶点缀（可循环低频） | 1 |
| bgm_chinese.mp3 | 古筝/笛子循环曲 | 1 |
| bgm_forest.mp3 | 鸟鸣溪流自然音循环 | 1 |

**SoundManager**：
- 启动时加载全部到 `Map<SoundType, Media[]>`；播放池=8 个 MediaPlayer 轮换复用（防 GC 堆积）
- 变调：`player.setRate(0.92 + Math.random()*0.16)` 制造微妙差异
- 悬停音音量=总音量×0.15；落子=×1.0；终局=×1.0
- 所有播放 try/catch 包裹，**素材缺失时静默跳过，游戏照常可玩**

**MusicManager**：两轨循环（`setCycleCount(INDEFINITE)`）按 musicVolume 混音同时播放；开关做 500ms 淡入淡出

**SettingsStore**：文件 `用户目录/.gobang/config.properties`，键：`music.volume / sfx.volume / music.muted / sfx.muted`；启动读、修改即写（写失败静默）

### 3.8 动画与特效（fx/）

- **ForestBackground**：静态 Canvas 绘制一次（天空线性渐变→远山两层锯齿剪影→太阳光晕→侧边树影（树干矩形+树冠圆形簇）→底部草地→四角暗角）；叶子层独立 Canvas 叠上方
- **LeafAnimation**：8~10 片，每片参数(x, y, 下落速度30~80px/s, 左右摆动幅度20~40px, 自转角速度, 尺寸8~20px, 颜色黄/绿/棕)，`AnimationTimer` 60fps；y>900 从顶部随机 x 重生（错开相位防同排）；**窗口失焦时暂停**；对局终局时临时增至 40 片做花瓣庆祝 3 秒后还原
- **ShakeEffect**：Timeline 平移棋盘节点——落子：幅度3px/150ms；终局：8px/600ms + 整体 Scene 根节点 5px 摆动
- **WinEffect**：胜方 5 子画发光圆环（ScaleTransition+透明度脉动 2 次）+ 连线描边动画
- **弹窗**：半透明黑罩 + 圆角面板（木色），按钮统一样式

### 3.9 主菜单与场景切换

- `Main` 持单一 `Stage`，`MenuView`/`GameView` 根部都含同一个 `ForestBackground` 实例（切换不重建背景，省资源）
- 菜单流程：标题「五子棋」→「人机对战」「双人对战」两按钮 → 选人机时出现难度三选一（默认中等）→「开始对局」→ 进入猜先
- 对局页底栏：模式/难度文字 + 悔棋 + 重新开局（带确认弹窗）；顶栏回合指示+「制作：林森lsjs」（菜单页脚同标注）
- 返回菜单：清理对局（BGM 持续），从内存丢弃对局对象

## 5. 并发与竞态防护（重点防 bug 设计）

| 风险 | 防护 |
|---|---|
| AI 计算中用户悔棋/重开 | THINKING 态禁止悔棋；重开需确认，确认时递增生成号，AI 回调校验生成号不符则丢弃结果 |
| AI 完成回调晚于重开 | 生成号机制（唯一竞态锁点） |
| 快速连点按钮/弹窗 | 弹窗单实例守卫；状态机前置校验 |
| 悬停越界 | clamp 函数单点实现，覆盖测试 |
| 音效爆音/内存 | 8 播放池轮换 + 音量钳制[0,1] + 素材缺失静默 |
| 窗口关闭残留线程 | Stage onCloseRequest → 停 BGM/叶子/摇晃 |

## 9. 风险与回退方案

- 素材下载失败 → 回退：程序合成音（Java Sound API 正弦波敲击/鼓点）
- 落叶性能问题 → 降帧至 30fps 或减至 6 片
- 困难 AI 超时 → 深度降到 1 层 + 启发式增强

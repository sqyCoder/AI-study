# 「蛇途求生」V2 大改版开发计划

基于 spec1.md 的功能基线,针对以下大项进行改版:棋盘适配核查、速度规则、陨石预警、道具系统重构(主动/被动两分类)、事件系统调整、刷新调度、开局保护移除。本计划为 V2 开发唯一依据,开发必须严格遵守。

---

## 二、速度规则(需求 2、7)

### 2.1 配置变更(`js/config.js`)
| 字段 | 原值 | 新值 |
|---|---|---|
| `baseSpeed` | 2 | **4** |
| `maxSpeed` | 6 | **10** |
| `speedMaxMul` | 3 | **2.5** |
| `speedScoreStep` / `speedPerStep` | 100 / 0.05 | 不变 |

- `speedMaxMul = maxSpeed / baseSpeed = 10 / 4 = 2.5`,对应约 3000 分封顶。
- `scoring.js` 公式已读 config,仅需保证 `difficultyMul` 用 `speedMaxMul` 取 min、`baseSpeedFor` 用 `baseSpeed` 即可,无需改逻辑。
- 速度平滑渐变 `lerpSpeed`(3 秒过渡)保留。

### 2.2 速度修饰(全部保留,作用于 4 基础)
- 减速时钟:`×0.7`(-30%,主动道具)
- 节奏波动事件:`×1.15`(+15%)
- 赌博减速:`×0.5`(-50%)
- 赌博加速:`×2`(A1 副作用)
- 综合公式:`最终速度 = 4 × 难度倍率 × 道具减速 × 赌博减速 × 事件系数 × 赌博加速`,多个减速乘算。`scoring.finalSpeed` 保持不变。

### 2.3 UI
- HUD **不显示**实时速度(维持现状,`UI.setSpeed` 保持空实现)。

### 2.4 测试更新
- `tests/run.js` 速度曲线:
  - `difficultyMul(0)=1`、`difficultyMul(100)=1.05`、`difficultyMul(3000)=2.5`(封顶)、`baseSpeedFor(0)=4`、`baseSpeedFor(3000)=10`。
  - `finalSpeed` 综合公式示例用新基准重算。
- `tests/probability.js` 不受影响(不含速度)。

## 三、陨石预警(需求 3)

### 3.1 现状问题
- 现实现:预警期 2 秒内**同时**闪烁 5 个落点 3×3 轮廓,预警后每 2 秒降 1 块。用户认为落点提示停留过短且全部同时出现。

### 3.2 新规则
- **逐个预警**:每个陨石落点在其**落下前 1 秒持续显示**预警标识,一次只显示一个;该块降落后才显示下一块预警。
- 时序(`perDrop = 2s`,共 5 块):
  - 块 1:预警 `[0, 1)` → 落点于 `t=1`
  - 块 2:预警 `[2, 3)` → 落点于 `t=3`
  - 块 3:预警 `[4, 5)` → 落点于 `t=5`
  - 块 4:预警 `[6, 7)` → 落点于 `t=7`
  - 块 5:预警 `[8, 9)` → 落点于 `t=9`
  - 末块落地后 `lingerAfterLast = 3s` → 全部同时消失(`t=12`)。
- 预警时长固定 **1 秒**(区别于原 1~2 秒随机);预警标识为单个落点 3×3 轮廓闪烁。

### 3.3 实现改动
- `js/logic/events.js`:
  - 移除预警期「全部中心」;新增「当前即将降落落点」状态。
  - `meteorTick` 逐块调度时,于每次降落前 1 秒写入当前预警中心点。
  - `currentWarning()` 返回 `{ type:'meteor', center: 当前块中心 }`。
- `js/render/renderer.js` `drawWarnings`:仅绘制当前单个中心点的 3×3 轮廓(持续闪烁,1 秒)。

### 3.4 测试更新
- 新增:陨石 5 块逐个调度、每块预警 1 秒、任意时刻至多 1 个预警落点、末块后 3 秒全部消失。

## 四、道具系统重构(需求 4,核心)

### 4.1 两分类总览

**主动(入 3 格道具栏,点击即用,栏内显示名称):**
| 类型 | 名称 | 效果 | 时长/说明 |
|---|---|---|---|
| `slow` | 减速时钟(有) | 移动速度 -30% | 5 秒,点击后倒计时环 |
| `shrink` | 收缩药剂(有) | 蛇身 -3 节 | 即时,最低 3 节 |
| `ghost` | 幽灵药剂(新) | 可穿透自身蛇身 | 5 秒;结束瞬间头在体内 → 判死 |

**被动(拾取即时生效,不占栏):**
| 类型 | 名称 | 效果 | 说明 |
|---|---|---|---|
| `golden` | 黄金苹果(新) | 分数 +50、蛇身 +3 节 | 即时,吸引主动走位 |
| `poison` | 毒苹果(新) | 蛇身 -1 节 | 即时,最低 3 节 |
| `foodRain` | 食物雨(新) | 10 秒内每 1s 生成 1 个普通食物,场上总数上限 8 个,结束后仅留 1 个 | 持续,事件条显示 |
| `magnet` | 磁力吸盘(新) | 8 秒内将曼哈顿 ≤4 格普通食物逐格拉向蛇头(每 tick 1 格),进嘴即吃 | 持续,事件条显示,纯增益 |
| `shield` | 能量护盾(改被动) | 获得 1 层护盾(上限 2 层),可挡 1 次致命碰撞 | 角标 pill 保留 |
| `double` | 双倍得分(改被动) | 接下来 3 个食物得分 ×2 | ×2 徽章保留 |

- **删除 `reverse`(反向操控)** → 移入事件(见第五章)。
- 分类判定:`shrink` 虽为即时效果但归属**主动**(需点击使用),与「被动即时生效」区分:主动 = 进栏待点击,被动 = 拾取即触发。

### 4.2 刷新机制(`js/logic/items.js`)
- 刷新间隔 **30 秒**(`itemRefreshInterval` 60→30)。
- 开局立即刷 1 个道具(`itemFirstImmediate = true`),**类型全随机**(含负面)。
- 类型决策:增益 55% / 负面 45%;
  - 增益池 `GAIN_TYPES = ['golden','foodRain','magnet','shield','double','slow','shrink','ghost']`(8 种)
  - 负面池 `BAD_TYPES = ['poison']`(1 种)
  - 保底「连续两个道具不会均为负面」保留(`badNoConsecutive`);reverse 的 60s 冷却项删除。
- `firstBenignWindow` 置 0(前 30 秒禁负面移除)。

### 4.3 主动道具库存与使用
- 新增主动库存 `inventory`(3 槽,每槽对应一个类型:`slow` / `shrink` / `ghost`)。
- **拾取**(蛇头走到道具格):
  - 被动 → 立即 `apply`。
  - 主动 → 写入对应槽(同类型刷新覆盖);若 3 槽已全部持有其他类型 → **无法拾取**,道具留在场上。
- **使用**(玩家点击道具栏槽位)→ `api.useActiveItem(type)`:
  - `slow`:置 `effects.slow`(5 秒)。
  - `shrink`:`snake.shrink(3)`,槽清空。
  - `ghost`:置 `effects.ghost`(5 秒)。
- 槽内展示:图标 + 名称(`SLOT_LABELS`);使用后按类型显示倒计时环(仅 slow / ghost)。
- `UI.updateItemBar` 由「按 effects 状态」改为「按 inventory + effects」合并渲染。

### 4.4 被动即时效果
- `golden`:`game.score += 50`;`snake.growTail(3)` 并实际追加 3 节(参考赌博 `grow10` 的尾节追加实现,含棋盘容量上限防御)。
- `poison`:`snake.shrink(1)`(最低 3 节)。
- `shield`:`effects.shield = min(+1, 2)`。
- `double`:`effects.double = { count:3, until: now+10 }`。
- `foodRain`:`effects.foodRain = { until: now+10 }`;生效期间事件条显示。
- `magnet`:`effects.magnet = { until: now+8 }`;生效期间事件条显示。

### 4.5 多食物重构(`board.food` → `board.foods[]`)
- 波及:
  - `js/main.js`: `board.food` → `board.foods`(数组);`spawnFood` / `shiftFood` 操作数组;吃食判定遍历任一食物;`foodShift` 事件需重排全部食物。
  - `js/logic/grid.js` occupancy 的 food provider:返回数组全部格。
  - `js/render/renderer.js` `drawFood`:遍历绘制所有食物。
  - `js/logic/events.js` `foodShift` 事件:对所有食物重排。
  - 磁力吸盘:对所有食物做吸附。
  - 食物雨:每秒 `push` 1 个食物(上限 8),结束后裁回 1 个。
- 普通食物得分公式 `(10 + 蛇身长度) × 倍率` 不变。

### 4.6 图标方案
- **内联 SVG 手绘拟物图标** + 荧光描边,棋盘内 `drawItem` 直接绘制形状,道具栏 `UI.SVG` 统一模板。
- 各类型图形:苹果(golden)/ 骷髅苹果(poison)/ 云+雨滴(foodRain)/ 磁铁(magnet)/ 时钟(slow)/ 注射器(shrink)/ 幽灵(ghost)/ 六边形盾(shield)/ ×2 徽章(double)。
- 棋盘内占用格需保证视觉辨识度高、霓虹风格统一。

### 4.7 测试更新
- 道具池:增益 8 / 负面 1;55/45 分布;连续负面不出现。
- 主动库存:拾取进栏、同类型刷新、满栏无法拾取、点击使用、shrink 即时清槽。
- 被动:golden 加分加长、poison 减长最低 3、foodRain 多食物上限 8、magnet 吸附逐格移动。
- ghost:5 秒穿透、结束判死。

## 五、事件系统(需求 5)

### 5.1 事件池(6 种)
| 事件 | 分类 | 改动 |
|---|---|---|
| `blockade` 障碍涌现 | 负面 | **修改**:4 块各 1 格,逐个生成,残影预告;空位 <10 → 转陨石 |
| `foodShift` 食物瞬移 | 中性 | 适配多食物数组 |
| `surge` 节奏波动 | 负面 | 不变 |
| `meteor` 陨石降落 | 负面 | **预警改逐个 1 秒**(见第三章) |
| `visionShrink` 视野收缩 | 负面 | 不变 |
| `reverse` 反向操控(新) | 负面 | 4 秒,1 秒预警 |

### 5.2 障碍涌现修改
- 4 块障碍,每块 **1 格**,**逐个生成**。
- 生成节奏:每 1.5 秒生成 1 块;每块在生成前 1.5 秒显示**残影**(该格的紫红轮廓/残影预告)。
- 时序:块 1 残影 `[0,1.5)` 实体化于 `t=1.5`;块 2 残影 `[1.5,3)` 实体化 `t=3`;块 3 `t=4.5`;块 4 `t=6`;事件在 `t=10` 时全部障碍消失。
- 障碍不与蛇头 3 格(曼哈顿)、食物、蛇身、其他障碍/道具重叠(沿用现有生成约束)。
- **空位 <10 转陨石**:触发 `blockade` 时,若 `freeCells().length < 10`,改为触发 `meteor`(中心点避开蛇头 3 格,用新版逐个 1 秒预警)。此为障碍事件的空间不足兜底。

### 5.3 反向操控事件
- 参数:`duration = 4` 秒、`warning = 1` 秒。
- 效果:方向键输入反转(上↔下、左↔右),复用现有 `effects.reverse` 与 `isReversed()`。
- 预警形式:方向键区红色闪烁(`dpad button.alert`) + 顶部事件条。
- 加入 `BAD_EVENTS`,负面概率均分纳入;赌博 A3「10 秒按键反向」独立保留(互不影响)。

### 5.4 通用规则
- 触发间隔 **50 秒**(`eventInterval` 45→50)。
- 事件首延迟 **置 0**(`eventFirstDelay` 60→0,移除开局保护)。
- 保底保留:负面 75% / 中性 25%、连续两次事件不会均为负面、同一种负面事件 120 秒冷却。

### 5.5 测试更新
- blockade:4 块逐个、每块 1.5s、残影 1.5s、空位 <10 时返回陨石、时长约 10s。
- reverse 事件:4s 生效、1s 预警、方向反转。
- meteor:逐个 1 秒预警(见第三章)。
